# MathInputTool - 高效数学公式输入工具

[![License](https://img.shields.io/github/license/bigroc1983/math-input-tool)](LICENSE)
[![Release](https://img.shields.io/github/v/release/bigroc1983/math-input-tool)](https://github.com/bigroc1983/math-input-tool/releases)

一个开源、跨平台的悬浮式数学符号与公式输入助手，让你在 Word、记事本、LaTeX、网页中都能瞬间输入数学表达式。

## ✨ 核心功能

- **全局悬浮窗**：按 `Ctrl+Shift+M` 唤起，在任何窗口上显示
- **200+ 数学符号**：希腊字母、运算符、微积分、函数、集合等
- **智能搜索**：拼音、英文、LaTeX 命令皆可搜
- **双击/回车即上屏**：无缝粘贴到目标文档
- **LaTeX 实时预览**：选择模板时可看到排版效果
- **完全开源免费**：基于 Electron + Vue 3 构建

## 📥 下载与安装
